1 控制台添加自定义域名

  1. 打开控制台：https://console.tencentcloud.com/edgeone/pages，进入项目 protobuddy
  2. 左侧菜单 → 域名管理 → 点击 添加自定义域名
  3. 输入域名：protobuddy.20140107.xyz（子域名，关联生产环境）
  4. 弹窗会给出两条信息，请复制保存（下一步要用）：
    • 归属权验证记录（TXT 记录：主机记录 + 记录值）
    • CNAME 目标（形如 xxxxxxxx.protobuddy.20140107.xyz.dns.edgeone.site.）
⚠️ 关键前置：本项目加速区域为 overseas（不含中国大陆），无需 ICP 备案。若曾在控制台误选「全球可用区(含中国大陆)」，绑定会要求备案 —— 本项目已确认为 overseas，无需担心。

2 Cloudflare 添加 DNS 记录

域名 20140107.xyz 的 DNS 托管在 Cloudflare（NS: jeff/lia.ns.cloudflare.com）。登录 dash.cloudflare.com → 选择 20140107.xyz → DNS → 记录，添加两条：

类型名称内容
TXT按控制台弹窗（一般为 _edgeone 或类似）按控制台弹窗提供的值（归属验证）
CNAMEprotobuddy控制台提供的 CNAME 目标（xxx.dns.edgeone.site.）

代理状态：DNS only（灰云）即可，EdgeOne 需要看到真实 CNAME。

验证：dig CNAME protobuddy.20140107.xyz

生效后回到控制台域名管理页，状态列显示 已生效 即完成；SSL 证书由 EdgeOne 自动申请签发（免费，自动续期）。

3 访问验证

  1. 等待证书签发（一般几分钟，控制台域名状态显示「已部署」）
  2. 浏览器访问 https://protobuddy.20140107.xyz，应看到平台首页
  3. API 验证：curl https://protobuddy.20140107.xyz/api/health → {"status":"ok",...}

4 后续部署到该项目的命令

npx edgeone makers deploy . -n protobuddy -t "<token>" -e production --json -a overseas

⚠️ 注意 -a overseas 必须保留——若用 -a global 部署会因「全球可用区(含大陆)」而要求备案。

背景说明

  • 为什么不用默认的 global 区域？ 实测 CLI -a global = 全球可用区(含中国大陆)，绑定自定义域名需工信部备案；-a overseas 无需备案。你的域名在 Cloudflare（海外托管）大概率未备案，故采用 overseas。
  • 区域差异实测：global 项目无 token 直连返回 401（3 小时预览链接模式）；overseas 项目直连 200（海外网络可直连，中国大陆网络返回 401，绑定自定义域名后为稳定通道）。
  • 绑定只能控制台：CLI 与 Pages Open API 均无自定义域名 Action（已逐一探测），需登录控制台操作。可先把弹窗里的 TXT/CNAME 值发我，我用 Cloudflare API 帮你加记录（需你提供 Cloudflare API Token）。
